# Calendar Today

Answers: what is left today, and what is the next thing on the calendar?

Reads: the calendar bridge's day view (the same calendar file your flow syncs). No workspace files.

Shows: events today (metric), what is left (list of rows), next event title (text).

Never: writes to the calendar, asks the model, or reads mail and files outside the calendar bridge.

Missing data: when the bridge is absent or stale the card renders blank with the bridge's cause instead of a zero.
