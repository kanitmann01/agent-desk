# Design Language: Agent Desk (working name)

Direction pass per `ui-design` (product-ui track). Baseline candidate generated by `ui-ux-pro-max --design-system --density 8`, then refined; deviations from the generator are listed at the bottom. This document is the source of truth the build consumes.

## Visual thesis

A quiet instrument with warm competence: the calm density of Linear crossed with the friendly clarity of Things 3, on warm paper rather than dev-tool charcoal. It should read like a well-made ledger, an object Priya trusts at 8:55 before a meeting, not a control room. Structure is felt through hierarchy and spacing; the work surface is louder than the chrome.

Personality: warm/approachable + trust/financial. Light mode only in v1 (office, browser, WebView2).

## Type

- UI: **Plus Jakarta Sans** (400, 600, 700, 800). Humanist-enterprise without being Inter.
- Numbers, timestamps, IDs: **IBM Plex Mono** (400, 500, 600), always tabular. Numerals are the product's voice; they get their own face.
- Scale: 12 (stamps, labels), 13 (secondary), 14 (body, controls), 16 (card titles), 20 (section), 28 (page greeting, once).
- Sentence case everywhere. No oversized display numerals: the KPI number is 28px mono, not a 64px hero.

## Component rules

- One depth strategy: hairline + layered shadow (`--shadow-card`), hover raises each opacity by ~0.02, 200ms ease. No borders-plus-heavy-shadow mixes.
- Concentric radius everywhere: button radius 8, chip 6, card 12 with 12-16px padding.
- Buttons: solid deep green primary, one per surface; quiet outline secondary; ghost icon buttons with hairline hover fill. Stable dimensions across label/loading changes.
- Widgets are not a uniform card mosaic: sizes vary by role (7/5, 8/4 columns), internals differ, and each carries the same three-part header contract: title, freshness stamp, overflow menu.
- Color only for status and action. Green = primary/up, amber = attention (pilot, stale), red = down/destructive. Nothing else is colored.
- Icons: one family, inline SVG, 1.5px stroke, round caps, 16/18px. No emoji, no icon backgrounds, no decorative icons. Every icon-only control has an aria-label.
- Copy is utility copy: orientation, status, action. No hero lines, no metaphors, no "your AI copilot" language on the work surface.

## Motion

150-200ms ease, opacity/color/shadow only. Reduced-motion: everything degrades to instant state change. No entrances, no stagger, no parallax. The only permitted "delight" is functional: a check mark filling, a card folding away on dismiss.

## Anti-slop commitments (checked at every review)

1. No gradients, glass, glow, noise, grids-as-atmosphere.
2. No repeated identical card grid; hierarchy comes from data, not the grid.
3. No emoji icons; no mixed icon families.
4. No marketing copy on product surfaces.
5. Color never decorates; it states status or hosts the single action.
6. Every size, gap, radius, weight traces to a token above or a named optical exception.
7. Fabricated proof (fake logos, invented stats) never appears; sample data is labeled "sample".

## Deviations from the generator baseline

- Replaced flat teal #0D9488 + orange #EA580C (a stock SaaS pairing, two competing accents) with deep green #14594E on warm paper; amber kept only for attention states, demoted from CTA.
- Replaced white-on-teal mass fills with white cards on paper; depth via the ui-design layered-shadow formula rather than strictly flat, because the paper background needs card separation.
- Kept: Plus Jakarta Sans, density 8 (compact spacing), light mode, 150-200ms transitions, the no-emoji/SVG-icons and contrast checklist.
