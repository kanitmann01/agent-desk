The facts

  • Processes started: none. The app never launches another program.
  • Persistence: none. No Run key, no scheduled task, no service. The app runs only while you keep it open.
  • Network: only the company LLM endpoint, only derived text, every call logged in the audit you can export as CSV.
  • Mail: off by default. When enabled, the app reads only the headers of the .eml files in a folder you choose (From, To, Cc, Subject, Date, Message-ID, In-Reply-To); message bodies are discarded at parse time and never reach any model, any store or any page, and accepted reply drafts are written as files to the local outbox folder for you to send yourself.
  • Data location: C:\Users\mannk\AppData\Local\Temp\agentdesk-evidence-cx8kh7d9. The watched workbook is copied to the temp folder before parsing and never modified.
  • Change ledger: every change the desk makes by itself is recorded in ledger.sqlite3 in that folder, with the before and after state of each change so Undo can put it back; the undo is itself recorded and can be undone in turn.
  • Uninstall: delete the folder. Nothing is left behind, nothing to unregister.
  • License: the core app is proprietary, all rights reserved; the plugin SDK is Apache-2.0. The Python runtime ships one third-party dependency, cryptography (memory encryption at rest; Apache-2.0 OR BSD-3-Clause), recorded with the dashboard bundle's documented, licensed set in THIRD-PARTY-NOTICES.md.
