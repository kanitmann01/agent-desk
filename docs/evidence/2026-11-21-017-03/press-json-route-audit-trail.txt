Agent Desk, spec 017 workstream 3: the pressed-card JSON route writes
the audit rows its no-JS twin writes. Real server, temp data dir,
tools/mock_endpoint.py as the endpoint on 127.0.0.1:63875/v1.

1. Bootstrap exchange: GET /auth/... -> 303 + session cookie (the launcher's browser does this).

2. Priya presses an explain card on the dashboard. The SPA posts the
   press payload to the JSON door, /api/insight/draft:
   POST /api/insight/draft -> 200
   status='draft' source='model'
   text='The mock endpoint answers a plain prompt with this sentence.'

3. The IT surface: the audit export (GET /audit/export.csv):

   agent-desk,insight.press,explain-range,2026-11-21T09:24:44

   which carries the columns the CSV leaves for the page: model, status:
