# Server core audit (verified at 6bb5bbb, code read by audit-server)

1. MUST FIX - Origin "null" bypasses the guard on every mutating route. src/agentdesk/server/guard.py:88-91. Any other server on 127.0.0.1:<other port> is same-site (cookies are not port-scoped; SameSite compares scheme+domain), so a sandboxed iframe there sends Origin: null, the session cookie rides along, Host 127.0.0.1:<port> passes, and POST /settings/toggle or /memory/* is accepted. The comment at guard.py:74-81 only reasons about cross-site, not cross-port.
