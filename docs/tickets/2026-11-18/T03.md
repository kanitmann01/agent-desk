# T3: Build the Outlook brief from headers only

Part of specs/008-plugin-truth-and-outlook-brief.md (G4). Reproduced 2026-11-18:

## Context

The Outlook card showed a message count, a sender list and a scope line. The ask
is a digest, the most important message, and reply starters inside the plugin.

## Scope

- src/agentdesk/mail/brief.py: score header-only messages for urgency and
  freshness, build digest rows, pick the top message with a "why", and produce
  three reply starters from the subject line only.
- Read Importance/X-Priority in the .eml parser.
- New data source `outlook-brief`, wired through plugin sources, validator and
  marketplace policy, binding messages, threadRows, topEmailSubject,
  topEmailLine, topEmailWhy and replyOptions.

## Acceptance

With mail_folder pointing at the mock inbox and mail_enabled on,
/api/plugins/outlook-digest/retest returns messages > 0, a nonempty digest, a
topEmailSubject, a topEmailWhy and three reply starters. No body text appears.
