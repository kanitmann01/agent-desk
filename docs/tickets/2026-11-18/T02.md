# T2: Install a Studio-created plugin on this desk

Part of specs/008-plugin-truth-and-outlook-brief.md (G2). Reproduced 2026-11-18:

## Context

Studio validated a draft and then stopped at "Pending review". Approval requires
AGENTDESK_MARKETPLACE_ADMIN=1, so a normal desk could never finish creating and
using a plugin. Publishing for distribution is a separate concern.

## Scope

- New non-admin route POST /api/marketplace/studio/install: validate the inline
  manifest, widget.ui.json and sample, write the exact tree, and install it with
  the plugin runtime.
- Studio gains an "Install on this desk" action after validation, plus a clear
  installed state linking to /marketplace/installed.
- Publishing for review stays optional; its copy no longer claims to be the only
  end of creation.

## Acceptance

A created plugin with one metric element validates, installs, appears in the
Installed list and on the dashboard with its sample. An invalid draft is refused
before anything is written. Tests cover both.
