# T4: Ship the Outlook Brief plugin, mock inbox and export helper

Part of specs/008-plugin-truth-and-outlook-brief.md (G3). Reproduced 2026-11-18:

## Context

Outlook.exe exists on the demo laptop but no mail profile is configured. The app
needs a rehearsed input shape plus a real-machine path, without Graph or OAuth.

## Scope

- tools/export-outlook.ps1: export header-only .eml from a configured Outlook
  profile via COM; plain message when no profile exists.
- demo/outlook-inbox/: six checked-in .eml files covering a thread, high
  importance, a direct ask, a low-priority note and a no-reply sender.
- registry/plugins/outlook-digest 0.3.0: dataSource outlook-brief, 2x2, six
  render elements for digest/top/reply starters; updated README, skill and
  sample; pins resynced and catalog rebuilt.

## Acceptance

The six .eml files parse; the helper exits with a plain no-profile message; the
plugin installs from the bundled catalog and its test asserts the three sections
with no body content.
