# T1: Make every local registry pin match the plugin tree

Part of specs/008-plugin-truth-and-outlook-brief.md (G1). Reproduced 2026-11-18:

## Context

24 of the 25 local-release pins in registry/index.json did not equal the
tree digest of the plugin directory they named. Installing Outlook Digest failed
with `install:hash-mismatch` before any card appeared, and issue #115 stayed red.

## Scope

- Recompute every local pin with the registry's own tree_digest.
- Rebuild src/agentdesk/marketplace/bundled-catalog.json from those pins.
- Keep the append-only history honest: an old version that the flat folder no
  longer contains becomes a tag release, not a fabricated local pin.
- Add/keep a test that fails when a pin drifts.

## Acceptance

`python scripts/sync_registry.py` reports 0 changed pins on a clean tree; the
four registry test files pass; installing outlook-digest, excel-report,
research-brief and sales-delta-widget from the bundled catalog succeeds.
