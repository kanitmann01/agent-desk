# T2: One-click source pickers

Part of specs/004-personal-agent-plugins.md.

## Context

The built-in sales card already opens a workbook picker, and the calendar walkthrough and the mail setting already connect those two sources. Plugin cards do not call any of them. A plugin with no config, after T1, has nowhere to send the user. This ticket connects the existing pickers to the config store.

## Scope

- Workbook, csv, and markdown plugins get one action, "Open a workbook" or "Open a markdown file", which calls the desk's existing file picker. The chosen path is staged, not confirmed, until the column step in T3 says confirm. For a plugin that needs no columns (none of the survivors, but the action must still be able to confirm a file-only source), confirm writes the config through T1.
- Calendar plugins' connect action opens the calendar walkthrough. Mail plugins' connect action opens the mail folder setting. The plugin does not store a second path. The card reads the desk connection.
- Page watch stages a URL. The host is parsed and shown. Saving records the optional network grant through the existing consent sheet, with the URL in the prompt. The policy allowlist is still checked before a fetch.
- Reconciliation stages two files. The config holds `left` and `right`. Confirm is still T3's job once columns exist. This ticket must be able to store both paths.
- Cancelling the picker writes nothing.
- The picker is local. It does not call the endpoint and does not read past the file the user chose.

## Acceptance criteria

- [ ] Choosing a workbook stages that path and no other file is read.
- [ ] Cancelling leaves the config absent.
- [ ] A calendar plugin's action opens the walkthrough and, once the walkthrough has a file, the plugin treats the calendar as connected without a path in its own config.
- [ ] A mail plugin does the same with the Settings folder.
- [ ] A page URL outside the policy allowlist can be saved and then fails the fetch with the policy reason. A URL on an allowed host is fetched only after the consent sheet is accepted.
- [ ] Reconciliation stores two distinct paths.

## Tests

- Extend `tests/test_plugin_config.py` for staging, cancel, and the two-path case.
- A server test that the calendar and mail connect actions redirect to the existing walkthrough and settings routes, using the harness in `tests/test_server_dashboard_api.py`.

## Out of scope

Column selection (T3), suggestion (T4), and the visual patterns (T5).
