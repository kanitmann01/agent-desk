# T7: Workbook tracker, and the three plugins that fold into it

Part of specs/004-personal-agent-plugins.md.

## Context

Excel Report Watch, Sales 24h Delta, Revenue vs Target, and Budget Burn are one reader with different literals: the `reports/*.xlsx` glob twice, a 1,000,000 USD progress target, and a 250,000 USD cap. Sales 24h Delta's changed-row list is empty because the manifest declares no key column. This ticket makes `excel-report` the tracker and turns the other three into named instances that open the picker.

## Scope

- `excel-report` declares `config.kinds: ["workbook"]`, drops the `reports/*.xlsx` glob, and uses the tracker pattern: figure, sparkline from stored snapshots (12 to 30 points, one per successful read), delta in the tracked unit, file name in the footer, optional goal.
- Optional changed-row list, capped at 8, only when a label column is set. Omitted otherwise.
- Optional pace mode: the user sets a plan amount, the days in the period, and the days elapsed. The card shows spent per elapsed day beside plan per period day. No plan amount is hardcoded.
- At most 6 instances, or fewer when `plugin_instance_cap` is lower. The seventh is refused.
- More than one instance per desk. Creating an instance asks for a name and opens the picker.
- `sales-delta-widget`, `revenue-vs-target`, and `budget-burn` are marked deprecated in the catalog and resolve to a new tracker instance named "Sales", "Revenue", and "Budget". Budget's instance records good direction `down`. The old numeric targets are not copied.
- An existing `excel-report` install with no columns opens the picker and does not read `reports/*.xlsx`. Old snapshot files are left on disk and are not plotted.
- The two skills become one tracker skill that reads the confirmed label and value and quotes at most two rows.
- Samples use generic labels and are renderable from the fixture bindings. No company names.

## Acceptance criteria

- [ ] A confirmed tracker instance shows the aggregate, a unit delta, and the file name, and does not read any other workbook.
- [ ] A second instance on the same desk has its own config and its own card. A seventh is refused at the default cap of 6.
- [ ] Pace mode shows spent per elapsed day beside plan per period day, using only numbers the user set.
- [ ] Updating `revenue-vs-target` opens a tracker instance named "Revenue" with no goal set.
- [ ] Updating `budget-burn` opens an instance named "Budget" with good direction `down` and no cap set.
- [ ] Sales 24h Delta's changed-row list is absent until a label column is confirmed, and then lists at most 8 keys.
- [ ] The old globs and the literals 1000000 and 250000 are gone from the four manifests.
