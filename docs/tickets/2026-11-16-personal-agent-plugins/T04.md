# T4: Suggest what to track, and confirm it

Part of specs/004-personal-agent-plugins.md.

## Context

The owner asked for an "AI suggest" option beside the column picker. The call has to be the host's, because Class D plugins do not get `llm.allow`, and it has to write nothing until the user confirms. A desk with no endpoint still has to be able to pick columns by hand.

## Scope

- A "Suggest what to track" action on the column step for workbook and csv sources only.
- The host sends the plugin's job sentence, the sheet name, and the header. It also sends at most five data rows, truncated to 8 KB, unless the setting `suggest_headers_only` is on. The file path is not included.
- Before the call, the picker shows the exact sentence for what will leave the machine. Headers only: column names, no cell values, no path. With rows: column names and up to 5 rows, no path.
- The call uses the desk's existing audited LLM path. The audit record includes the row count and the byte count.
- The reply is applied as a highlight on the column step: proposed roles, aggregate, and goal. Confirm writes the config with `suggested: true`. Dismiss writes nothing and leaves the hand-chosen columns as they were.
- A failed call leaves the step unchanged and shows the failure in one sentence.
- With no endpoint configured, the button is present, does not call anything, and says an endpoint is required. Hand confirm still works.
- Calendar, mailbox, research, page, and desk sources do not show the button.

## Acceptance criteria

- [ ] A suggestion request contains at most five rows and at most 8 KB, and does not contain the file path. With `suggest_headers_only` on, the request contains headers and no cell values.
- [ ] The picker shows the disclosure sentence that matches that mode before the call.
- [ ] Dismissing the proposal leaves no config file.
- [ ] Confirming the proposal writes the proposed columns and `suggested: true`.
- [ ] An endpoint failure writes nothing and the hand-picked columns can still be confirmed.
- [ ] No endpoint: the button explains, and a hand-picked config still saves.
- [ ] The audit log gains one record per suggestion attempt.

## Tests

- A scripted fake endpoint in the style of the research tests. Assert the request body bounds and both confirm and dismiss.
- A case with the endpoint unset.

## Out of scope

A model-written morning brief. Suggestion for non-tabular sources. Changing the research endpoint adapter.
