# T6: First-run and empty states

Part of specs/004-personal-agent-plugins.md.

## Context

A missing workbook today becomes an attention cause that names a glob, or a blank element. The built-in sales card already says "No workbook is connected" and offers "Connect a workbook". Plugin cards need that, per the spec's empty-state table, and they must not show a sample number or a zero while they are unconfigured.

## Scope

- Each survivor plugin has the empty state and the single action from the spec table. The action is the T2 picker, the calendar walkthrough, the mail setting, or the research field, as that row specifies.
- No config, no calendar, or no mailbox renders that state and binds no number.
- A connected source with a missing column renders "Change columns" and names the role. It does not render 0.
- Audit's empty log ("No audit events in this window.") is distinct from a missing callback ("Audit state is not available."). The same split for compliance and health, using the spec's sentences.
- Waiting on you with a connected mailbox and an empty follow-up list says "Nothing is waiting on you." Meeting prep with a calendar and no upcoming event says "Nothing upcoming to prepare."
- Installed cards never render `sample.json`.

## Acceptance criteria

- [ ] Each survivor's unconfigured card matches the spec sentence and shows no digit from a sample.
- [ ] A missing column names the role and offers "Change columns".
- [ ] The audit callback being unset and the audit log being empty produce the two different sentences.
- [ ] The marketplace sample still shows its fixture, with the Sample data chip, and an installed card does not use that fixture.

## Tests

- A parameterized test over the survivor ids asserting the empty-state sentence and the absence of a bound number.
- One installed-card test that a plugin with a sample fixture and no config does not return the fixture's values.

Rewriting the 25 manifests (T7 through T10). Suggestion copy.
