# T5: Card patterns, so the cards stop looking identical

Part of specs/004-personal-agent-plugins.md.

## Context

Discover draws 25 copies of one tile because the committed catalog pin drops `icon` and `summary`, and every pin falls back to the plug glyph. The marketplace sample puts every plugin in one `WidgetCard` grid. The dashboard's `PluginCardView` draws a metric and turns every other element into a note. Array-shaped tables (A/R Aging, Audit digest, Source Ledger) render their headers and an empty body, because the sample reads `row.primary` on an array. PR #117 is restyling the shell. This ticket styles the inside of the card to the nine patterns in the spec and fixes the two render bugs. It does not restyle the rail, the greeting, or the page frame.

## Scope

- Nine pattern renderers, used by both the dashboard plugin card and the marketplace sample: tracker, digest, agenda, briefing, watcher, scorecard, compare, checklist, status. Tokens are the ones PR #117 lands (2px black rule, Source Serif 4 for briefing prose and titles, IBM Plex Mono for figures, fir for up, oxide for down and for the action). If PR #117 has not merged, implement against its `specs/003-ui-ux-polish.md` tokens and keep the renderers isolated so a token rename is a stylesheet change.
- Dashboard plugin cards honor the pattern's span (8 or 4) and collapse to one column at the shell's existing breakpoint. They stop using a hardcoded `span-4` for every plugin.
- Table rows that are arrays render as cells, in order, under the declared columns. Dict rows still render as primary, secondary, meta.
- Discover tiles show the manifest icon at 16px in ink, with no filled well, and show the summary. Fix `build_bundled_catalog` so a pin that lacks `icon`, `summary`, or source kind is filled from the manifest instead of shadowing it. Rebuild `bundled-catalog.json` so a checkout without the merge still has those fields.
- The sample chip "Sample data" stays. Patterns do not add a second accent, a gradient, or an icon background.

## Acceptance criteria

- [ ] An array table fixture with three cells per row shows those three cells in the sample and on an installed card.
- [ ] A metric-only dashboard card is no longer the rendering of a list, a sparkline, or a timeline.
- [ ] Tracker, digest, briefing, and watcher fixtures are visually distinct: a figure plus sparkline, a ranked list, serif prose, a timeline. Covered by a rendered fixture assertion on the element structure and by a screenshot of the four fixtures.
- [ ] Discover returns a different icon and a non-empty summary for Calendar Today and for the Workbook tracker.
- [ ] Spans follow the pattern table in the spec at the desktop width, and collapse to one column at the narrow width.

## Tests

- Extend `tests/test_plugins_render.py` for array rows and for one fixture per pattern.
- Extend the marketplace catalog test so a thin pin gains `icon` and `summary` from the manifest.
- Frontend tests beside `frontend/src/test/widget-card.test.tsx` for the four pattern structures. Do not restyle unrelated marketplace pages.

## Out of scope

The shell, the rail, and the greeting (PR #117). Wiring real data into the patterns (T7 through T10). Empty-state copy (T6).
