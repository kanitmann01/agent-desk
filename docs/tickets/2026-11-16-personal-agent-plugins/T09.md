# T9: Calendar, mail, research, and page watch

Part of specs/004-personal-agent-plugins.md.

## Context

Calendar Today, Meeting Prep, and Week Load read one day view and each repeat today's rows. Meeting Prep's checklist is the string "Confirm with {name}", written by the calendar bridge. Outlook Digest and Sender Watch are the same mail digest. Waiting on you uses a 2-day constant and `employee@example.com`. Source Ledger's titles are empty because the store has none, and the sample invents them. Competitor Watch fetches `example.com` and cannot turn HTML into the price lines its sample shows.

## Scope

- Today uses the agenda pattern. The event count moves to the footer. No model call, same as now.
- Meeting prep shows the next event's title, time, location, and attendee names. Remove the "Confirm with" items from the plugin binding. If the Notes grant exists, list open checkboxes whose text contains an attendee name. Do not add a new filesystem grant.
- Week load keeps `weekHours` (7 days) and `weekPoints` (14 points) and drops today's list. The footer says "Next 7 days".
- Mail digest lists at most 8 senders by count. An optional substring filter is config. `vip-watch` redirects to the digest and does not pre-fill a filter. Bodies stay unread.
- Waiting on you: the figure is the waiting-list length. The threshold is a confirmed number of days, starting at 2 in the picker, not `FOLLOW_UP_DAYS` as a hidden constant. The self address comes from Settings when one is set. The 24-hour message count is removed from this card.
- Research brief adds the source list. A title or a used flag is shown only when the store record has it. `source-ledger` redirects here. Render does not call the endpoint.
- Page watch: one confirmed URL, a timeline of time, changed or unchanged, and HTTP status. The first 200 characters of a changed body are a disclosure. No price parsing. The policy allowlist still blocks a fetch. The sample is an "unchanged" timeline. The catalog name becomes Page watch. The id stays `competitor-watch`.

## Acceptance criteria

- [ ] Meeting prep's payload does not contain "Confirm with".
- [ ] Week load's payload does not include today's event rows.
- [ ] Mail digest and the old Sender Watch id render one card, and a filter limits both the list and the count.
- [ ] Waiting on you shows the waiting count. Changing the threshold from 2 to 5 changes which fixture threads appear.
- [ ] Research brief shows a source title only when the fixture record has one, and shows the bare string otherwise.
- [ ] Page watch does not fetch a host the policy rejects, and a changed HTML body is not parsed into price rows.
