# T8: Aging, scorecard, reconciliation, deadlines, and notes

Part of specs/004-personal-agent-plugins.md.

## Context

These five jobs stay because the card is not a single total. Each one still hard-codes a glob and column names, and three of them disagree with their own description: reconciliation's figure counts keys on both sides while the label says unmatched, renewal's window keeps dates far in the future, and follow-up never reads a promise column. Follow-up becomes a Deadlines instance.

## Scope

- Aging: roles `label`, `value`, `date`, plus editable bucket edges that start at 30, 60, 90 only as the picker's initial suggestion. The table is one row per bucket. The list is the oldest eight with age in days. The figure is the sum.
- Scorecard: roles `label`, `value`, `target`. Status sentence is "N of M off target", computed. No hero figure. Off-target rows use oxide.
- Reconciliation: two files, a key role on each. The figure is the unmatched count. The list is unmatched keys only, capped at 8, labeled with the file name. When the user also sets an amount role, a key on both sides with different amounts is unmatched and the row shows both amounts.
- Deadlines (`renewal-radar`): label and date roles, a day window the user confirms (picker starts at 30). The count includes today through the window and excludes past dates. Past dates sit in a collapsed "Passed" group. `follow-up-watch` redirects to an instance named "Promises" and does not assume `Owner` or `Due`.
- Notes: one markdown file, or a folder only when the user selects the folder. Heading chosen from the file's headings. Checkboxes and `due:` behave as they do now. The file is not written.
- All five drop their hardcoded globs and use T6's empty states.

## Acceptance criteria

- [ ] Aging on a fixture with two dates produces the bucket amounts and an age in days, not the raw date, on the oldest list.
- [ ] Scorecard "N of M" matches the fixture, and a row without a target is not marked off target.
- [ ] Reconciliation's figure equals the unmatched key count. With amount roles set, a shared key and two amounts counts as unmatched.
- [ ] A deadline 31 days out is outside a 30-day window. A deadline yesterday is not in the count and appears under Passed.
- [ ] Follow-up's update path opens a Deadlines instance named "Promises" with no columns copied.
- [ ] Notes confirms a heading that exists in the file and does not modify the file.
