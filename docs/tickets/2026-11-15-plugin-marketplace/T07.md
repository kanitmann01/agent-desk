# T7: Finance plugins (6)

Part of #97.

## Context

The first batch makes the store non-empty and proves the capability model on real jobs. Finance is the highest-value cluster: the Monday A/R review, the quarter vs target question, and the reconciliation chore are the reasons people pin a dashboard.

## Scope

Ship six in-box plugins under `registry/plugins/<id>/`, each v2 manifest, sample fixture, and widget UI:

| id | Question | Source | Lead element |
|---|---|---|---|
| `sales-delta-widget` | What changed in the pipeline since yesterday? | excel-watch | delta |
| `revenue-vs-target` | Are we ahead or behind the quarter? | excel-watch | metric + progress |
| `ar-aging` | How much cash is stuck, and how old? | excel-watch | table (0-30/31-60/61-90/90+) |
| `budget-burn` | Are we burning faster than plan? | excel-watch | progress + status |
| `kpi-scorecard` | Which four numbers are off target? | excel-watch | list of status rows |
| `reconciliation-watch` | What is in the ledger but not the bank? | compare (two sheets) | metric + list |

- `sales-delta-widget` is an upgrade of the existing plugin. Keep its id so installed users do not lose it; bump version and add the v2 fields.
- Each plugin names the exact setting or file it needs in the blank state. No fake zero, no placeholder number.
- Each card carries the as-of stamp and the state from T2.
- Categories `finance`; tags for the job, not the vendor. Pack membership per the plan table.

## Acceptance criteria

- [ ] All six pass the validator as v2 and appear in the bundled catalog.
- [ ] Each executes against its fixture workbook and returns the documented lead value plus as-of and ok state.
- [ ] `ar-aging` buckets a fixture with known ages correctly and labels the table columns.
- [ ] `reconciliation-watch` reports left-only and right-only counts and lists the first five items.
- [ ] A missing workbook renders the blank state naming the setting, not zero.
- [ ] `sales-delta-widget` keeps its id and installs over the existing 0.1.0 without a purge.
- [ ] No plugin reads outside `${workspace}/`.

## Tests

Registry package seam: one test module for the batch that validates each manifest, renders the sample, and asserts expected values from fixtures. Fixture workbooks live under the test fixtures dir, not in user data.

## Out of scope

Remaining families (T8 to T11), packs (T12), UI polish (T15).
