# T14: Packaging, SBOM, and license gates

Part of #97.

## Context

A Python app on a locked-down Windows laptop needs one signed folder and no interpreter dependency. Distribution also needs a license position: the repo carries vendored and third-party material, and enterprise sale cannot ship a license landmine.

## Scope

- Nuitka one-folder build profile with a stable executable name and a documented AppLocker publisher rule for IT.
- Build script that produces the one-folder artifact and a manifest of contents; no admin rights required at run time.
- CycloneDX 1.6 SBOM generated in CI from the built artifact and from the Python dependency set.
- License gate: allowlist MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC; fail on anything else, including Commons Clause and unlicensed files. Upstream LICENSE files shipped for every bundled dependency.
- Regenerate THIRD-PARTY notices from the SBOM.
- Identify and record the repo's own distribution license position: proprietary core plus Apache-2.0 plugin SDK, with the SDK boundary documented.
- Remove or quarantine any license landmine found (the vendored react-bits components are the known one).
- CI job runs the gate, the SBOM generation, and the build smoke test.

## Acceptance criteria

- [ ] The one-folder build launches and serves the desk on a machine without Python installed (documented check).
- [ ] The SBOM lists every shipped Python and frontend dependency with versions and licenses.
- [ ] The license gate fails on a fixture dependency with a banned license and passes on the allowlisted set.
- [ ] THIRD-PARTY notices are generated, not hand-edited.
- [ ] Every bundled dependency ships its upstream LICENSE text.
- [ ] The known landmine is removed or quarantined and the gate stays green.
- [ ] The AppLocker publisher rule is documented with the exact publisher string.

## Tests

Build scripts are verified by running them in CI; the license gate gets a unit test over fixture SBOMs. No product code path changes.

## Out of scope

Procuring a real code-signing certificate, signing the binary in this environment, and AppLocker rollout.
