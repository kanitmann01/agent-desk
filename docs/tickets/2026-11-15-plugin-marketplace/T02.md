# T2: Data sources v2: real executors and honest states

Part of #97.

## Context

Lint knows twelve data source types; only four execute (`excel-watch`, `calendar-read`, `mail-digest`, `research-brief`). `json-watch` and `http-get` pass lint but fail at runtime. Every card must also carry an honest state, because "no data" and "zero" are different answers.

## Scope

- Executors for `csv-watch`, `json-watch`, `markdown-watch`, `manual-metric`, `desk-state`, `compare`, `aggregate`, `http-get`. Keep the four existing executors.
- Every payload uses `{value, asOf, source, state}` with state in `ok | stale | blank | coarse | partial` and a machine reason plus a human line.
- State rules: `ok` fresh and complete; `stale` source older than its window, last good value kept; `blank` file or connection missing, no number; `coarse` a declared fallback source was used, and the card says which one; `partial` only some rows parsed, and the card says "n of N".
- Source specifics:
  - `csv-watch`: delimiter, keyColumn, valueColumn, window, aggregate
  - `json-watch`: only `$.a.b` and `$.a[*].n` selectors; anything else rejected
  - `markdown-watch`: heading filter, checkbox extraction, `due:` markers
  - `manual-metric`: value, target, unit, cadence, history, stored under the plugin data dir
  - `desk-state`: runtime, audit, policy selectors; never reads user files
  - `compare`: two local sources, emits left-only, right-only, both, counts
  - `aggregate`: sum, count, latest, min, max over `requires[]`; a missing dependency is a named blank state; cycles rejected
  - `http-get`: GET only, declared host allowlist, no filesystem read in the same plugin, timeout, size cap, response hash diff
- Validator: a plugin declaring `http-get` and any filesystem read is rejected. Element and source compatibility is checked (sparkline needs a series, table needs columns, progress needs a target).
- Optional `fallback` source declaration is allowed for `excel-watch` to `csv-watch` with the same columns; when the workbook is missing and the CSV exists, the payload is `coarse`.
- HTTP transport is injectable so tests never touch the network.

## Acceptance criteria

- [ ] Each of the twelve source types executes against a fixture and returns `asOf` and `state`.
- [ ] Missing CSV yields `blank` with the missing path, never a fake zero.
- [ ] A file older than its window yields `stale` with the last good value and its date.
- [ ] A malformed trailing row yields `partial` and "n of N".
- [ ] Missing workbook plus present CSV fallback yields `coarse` naming the CSV.
- [ ] `http-get` plus any filesystem read is rejected by the validator; a timeout or oversized response yields `blank` with a reason, not a crash.
- [ ] An aggregate cycle is rejected; a missing dependency names the missing plugin.
- [ ] `json-watch` rejects selectors outside the mini grammar.

## Tests

Registry package seam: new `tests/test_sources_v2.py` with a fixture per source, state matrix tests, validator rejection tests, and a fake transport for `http-get`.
