# T15: Hardening, accessibility, theme pull-back, and e2e walkthrough

Part of #97.

## Context

The marketplace and the portfolio are built; this ticket is the closeout that makes the product demo-ready and consistent with the design system. The dashboard currently ships a dark-glass theme recorded as drift, which must not leak into the marketplace.

## Scope

- Pull the dashboard back to the warm-paper design system: one commanding green, monospace numerals, compact density, 12/8/6 radii, no gradients, glass, or glow.
- Accessibility pass on the marketplace and the dashboard: focus order, visible focus, heading structure, contrast, keyboard reachability, route announcement, no color-only status.
- Offline behavior: catalog from bundled plus installed, clear offline banner, retry.
- End-to-end walkthrough script for the demo: first run, pick a pack, see cards, open detail, install a plugin, widen consent, roll back, publish as pending review, approve, kill switch, export audit.
- Fix defects found during the walkthrough, including any state that renders a fake number.
- Closeout: update README or operator docs, record known limitations, and confirm no telemetry and no outbound calls outside the allowlisted network plugin.

## Acceptance criteria

- [ ] The dashboard and marketplace both use the design tokens; no dark-glass surface remains.
- [ ] The a11y checklist passes with keyboard-only navigation and a screen reader announcement per route change.
- [ ] Offline mode renders the bundled catalog and an offline banner, and recovers on reconnect.
- [ ] The walkthrough runs end to end without a console error and without a fabricated value.
- [ ] Any defect found is fixed or filed with evidence.
- [ ] Operator docs describe install, publish, policy import, and audit export.
- [ ] A final review confirms no telemetry and no unexpected egress.

## Tests

Full targeted suites green: registry package, server HTTP, SPA components. The walkthrough is recorded as a script and a short evidence log.

## Out of scope

New features. This ticket is hardening only.
