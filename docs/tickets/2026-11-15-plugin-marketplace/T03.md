# T3: Catalog, signing, and trust foundation

Part of #97.

## Context

Registry index v1 is a flat list with no signatures, no categories, no publisher identity, and no revocation. The client cannot prove that a plugin it renders is the plugin it installed. This ticket builds the trust spine once, used at install and again at load.

## Scope

- Ed25519 per RFC 8032, implemented in-repo with zero new runtime dependencies. Sign and verify, plus a detached signature envelope `{keyId, algorithm, signature, digest, signedAt}` over a canonical byte form.
- Trust metadata: org root with a 2-of-3 threshold, publisher delegation certificates (publisher id, key, provenance, expiry), release statements (plugin id, version, tree digest, changelog, category, minHost), and a revocation list with a monotonic `epoch`, a TTL, and revoked publisher, key, or release entries.
- Verification chain: root threshold, then publisher cert, then release statement, then plugin tree digest. Check the pinned anchor's epoch against the revocation list, check metadata expiry, and fail closed with specific codes: `trust:no-anchor`, `trust:bad-signature`, `trust:unknown-publisher`, `trust:revoked`, `trust:stale-epoch`, `trust:expired`.
- Install verifies digest, signature, and epoch. Load re-verifies the installed tree and fails closed if a file changed after install.
- Registry index v2: `schemaVersion: 2`, a monotonic version counter, generatedAt, publishers, per-plugin category and tags, releases with digest, signature envelope, changelog, yanked, minHost. A v1 index is wrapped into the v2 shape on load. Index v2 validation rejects unknown keys.
- Bundled catalog generator builds the catalog from `registry/plugins` plus trust statements into a build artifact. A test asserts every shipped plugin is present and each digest equals `tree_digest`.
- Fixture keys for tests are generated and never committed as secrets.

## Acceptance criteria

- [ ] RFC 8032 test vectors pass (empty message, 1-byte message, 1023-byte message), plus sign and verify round trips.
- [ ] A tampered digest, a tampered signature, or a signature from an unlisted key fails verification with the right code.
- [ ] A revocation epoch older than metadata expiry fails closed; a stale epoch fails closed; an expired publisher cert fails closed.
- [ ] Install refuses a package whose signature does not verify; load fails closed after a file is modified in place.
- [ ] A v1 index loads through the wrapper and yields the same plugin ids.
- [ ] The bundled catalog generator parity test passes for every shipped plugin.
- [ ] No new runtime dependency appears in `pyproject.toml`.

## Tests

Registry package seam: new `tests/test_trust_ed25519.py` (vectors), `tests/test_trust_verify.py` (chain, tamper, epoch, expiry), `tests/test_registry_index_v2.py` (schema and v1 wrapper), `tests/test_catalog_bundle.py` (generator parity).
