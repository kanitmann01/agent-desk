# T10: Research and knowledge plugins (4)

Part of #97.

## Context

The research store already exists and already produces sourced briefs. These four plugins make the knowledge usable at a glance and keep the source ledger visible, but they must not turn into a reading surface for arbitrary web content.

## Scope

| id | Question | Source | Lead element |
|---|---|---|---|
| `research-brief` | What did we learn most recently? | research-brief | text + sources count |
| `source-ledger` | Where did the last answers come from? | research-brief | table |
| `competitor-watch` | Did a watched page change? | http-get | delta + list |
| `notes-actions` | What did I say I would do? | markdown-watch | checklist |

- `research-brief` keeps its id and upgrades to v2.
- `source-ledger` lists title, domain, and fetched date for the latest brief, capped at 20 rows.
- `competitor-watch` is the single network plugin. GET only, host allowlist, no filesystem read in the same plugin, excluded from every pack, and install requires an explicit network consent plus admin policy. It ships as a reference-grade plugin flagged network in the catalog.
- `notes-actions` extracts unchecked checkboxes and `due:` markers from one markdown file, with a heading filter.
- Categories `research` and `command`.

## Acceptance criteria

- [ ] All four validate as v2 and appear in the bundled catalog; `competitor-watch` is marked network and excluded from packs.
- [ ] Each executes against fixtures and returns the documented lead value.
- [ ] `source-ledger` renders at most 20 sourced rows with domains and dates.
- [ ] `competitor-watch` with a policy that disallows network is ineligible, and with an allowlisted host performs one GET through the fake transport.
- [ ] `notes-actions` returns unchecked items with due dates and skips checked ones.
- [ ] A missing markdown file renders blank naming the file.
- [ ] `research-brief` keeps its id.

## Tests

Registry package seam: fixtures for the research store, one markdown note, and a fake HTTP response; plus policy ineligibility delegated to T4.

## Out of scope

Web browsing inside the app, content summarization, packs (T12).
