# T13: Signed policy, admin, and trust center

Part of #97.

## Context

Enterprise approval needs an artifact, not a settings page. The buyer's security team must be able to sign a policy, pin an anchor, kill a plugin, and export evidence. This ticket turns the eligibility fields from T4 into a verified bundle with an admin surface.

## Scope

- Signed policy bundle: mode, allowed publishers, allowed categories, risk ceiling, network allowlist, enabled sources, kill switch, retention, body-ingest flag, update channel, version policy, platform, minimum revocation epoch, signature requirement. Canonical JSON plus an Ed25519 envelope.
- Precedence: signed policy, then local admin setting, then built-in default. A bad signature or an expired bundle falls back to the curated default with a visible amber banner and an audit event.
- Import flow: choose a bundle file, verify, show the diff against the current policy, confirm. The policy file is the mutation of record; UI fields are read-only reflections.
- Admin surface under `/marketplace/admin`: posture, anchor fingerprint, policy verification status, pending publications with approve and reject, allowlists, revoked publishers with an epoch, inventory, catalog source, kill switch, audit export.
- Trust Center under `/marketplace/trust`: what is verified, how signatures work, what can never happen, how to report a plugin, and the last validator run.
- Audit export stays local JSONL. No telemetry.
- No fake RBAC and no multi-user. Admin is a policy-gated mode for the single Windows user.

## Acceptance criteria

- [ ] A signed bundle verifies and its fields take effect; a tampered bundle is rejected and the curated default stays active with an amber banner.
- [ ] A bundle with a lower revocation epoch than the pinned anchor is rejected.
- [ ] Policy import shows the diff before applying.
- [ ] A kill-switched plugin becomes ineligible and the admin surface shows the switch.
- [ ] Pending publications can be approved or rejected, and the decision is audited.
- [ ] The audit export downloads JSONL with installs, consents, denials, and egress, with no bodies.
- [ ] Trust Center renders the anchor fingerprint and the last validator run date.
- [ ] No route under `/marketplace/admin` is reachable without the admin mode and session.

## Tests

Server seam for policy verification, precedence, import diff, kill switch, and admin guards. Registry package seam for bundle canonicalization and signature checks. SPA component seam for Admin and Trust Center.

## Out of scope

SSO, RBAC, fleet management, central console, and cloud sync.
