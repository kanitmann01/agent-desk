# T12: Command plugins, role packs, and first-run

Part of #97.

## Context

Aggregates are how the desk answers "what matters today" without eight cards. Role packs are how a manager gets a coherent desk in one decision. Both depend on installed plugins and on a first-run path that does not dump the whole catalog on a new user.

## Scope

- `morning-brief`: aggregate of four declared dependencies, one list of four lead metrics, degrades to a named missing-dependency state.
- `weekly-review`: status plus list, aggregate over the week's deltas and stalled items.
- Both declare `requires` and are ineligible to install until the dependencies are present or installable in the same plan.
- Three packs as curated metadata: Manager (calendar-today, week-load, meeting-prep, follow-up-watch, sales-delta-widget, outlook-digest, research-brief, morning-brief), CFO (revenue-vs-target, ar-aging, budget-burn, kpi-scorecard, reconciliation-watch, renewal-radar, audit-digest, weekly-review), Ops (follow-up-watch, waiting-on-you, source-ledger, notes-actions, plugin-health, update-radar, compliance-posture, weekly-review).
- Pack install is one consent sheet and one request; if a member is blocked by policy the pack install reports the blocked member and installs nothing.
- First-run: when no plugin is installed, the desk offers the three packs plus a skip, and remembers the choice. Empty and demo states are labeled as sample data.
- Reference set: `excel-report` is reclassified as `reference` and excluded from packs while remaining installable and keeping its id.

## Acceptance criteria

- [ ] `morning-brief` and `weekly-review` validate with `requires` and render from fixtures.
- [ ] A missing dependency yields the named missing-dependency state, not a blank number.
- [ ] Each pack installs its members with one consent sheet and one API call.
- [ ] A pack with a policy-blocked member installs nothing and names the member.
- [ ] First-run appears only when nothing is installed, offers the three packs and skip, and the choice persists.
- [ ] `excel-report` appears under reference, is excluded from packs, and remains installable.
- [ ] Aggregates never fabricate a value for a missing member.

## Tests

Registry package seam for aggregates and pack metadata; SPA component seam for first-run and pack install flow. Server seam for the pack install-all request.

## Out of scope

All remaining plugin families are already covered by T7 to T11. No new runtime behavior.
