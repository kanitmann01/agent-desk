# T8: Snap the remaining off-scale type

Part of specs/003-ui-ux-polish.md.

## Context

After the title ceiling and the research field, many marketplace and dashboard sizes still sit between the named steps: 11px, 11.5px, 12.5px, 13.5px, 15px, 17px, 19px. The design language says every size traces to the scale 12, 13, 14, 16, 20, 28.

## What to build

A later pass maps each of those sizes onto the nearest named step without changing hierarchy: secondary text stays quieter than body, titles stay quieter than the greeting.

**Blocked by:** T4 (the ceiling and the sentence-case labels land first, so this pass does not fight them).

**Status:** deferred

## Scope

- Deferred. Not part of the first polish pull request.
- When picked up, change size only. Do not introduce a new face, weight, or color.

## Acceptance criteria

- [ ] Every font-size in the dashboard and marketplace stylesheets is one of 12, 13, 14, 16, 20, or 28px, or a documented optical exception.
- [ ] The greeting and the KPI value remain the only 28px objects on the dashboard.

## Tests

Extend the stylesheet contract test with the allowed size set.

## Out of scope

Server-rendered stylesheets (see T9).
