# T4: One title ceiling and sentence case

Part of specs/003-ui-ux-polish.md.

## Context

Marketplace page titles are 30px, and 25px on a narrow window, above and beside the 28px ceiling the dashboard greeting uses. Eyebrows, KPI labels, and section headings are uppercase, which the design language rules out. The marketplace main region clears its focus outline, so the skip link's landing spot has no ring.

## What to build

Marketplace titles use the same 28px greeting size at every width. Labels that were uppercase stamps become sentence case at least 12px. Keyboard focus on the marketplace main region shows the same green ring as every other control. The search field still shows its ring on the surrounding well, not a second ring on the input.

**Blocked by:** None (can start immediately).

**Status:** done

## Scope

- Page and detail titles at 28px, including the narrow-window override.
- Remove uppercase transforms from dashboard KPI labels and subheads, and from marketplace eyebrows, panel subheads, table heads, and sheet subheads.
- Those labels use the 12px stamp size where they were smaller.
- Marketplace main focus-visible draws the system ring. Mouse focus on the main region does not. The search input keeps its outline suppressed because the field well already draws the focus ring.

## Acceptance criteria

- [x] Marketplace titles are 28px at the desktop size and are not reduced to a second size on a narrow window.
- [x] The named labels are not uppercase.
- [x] A keyboard focus on the marketplace main shows a visible ring.
- [x] The search well still shows its focus ring.

## Tests

Stylesheet contract test for the title size, the removed uppercase transforms, and the main focus-visible ring.

## Out of scope

Resizing every 13.5px body paragraph in the marketplace. That long tail is T8.
