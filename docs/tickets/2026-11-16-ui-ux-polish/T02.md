# T2: Empty-state file names stay whole

Part of specs/003-ui-ux-polish.md.

## Context

The calendar empty state tells Priya which OneDrive file to expect. The path is a code span with spaces around it, and the hyphen in the folder name is a break opportunity, so the name splits mid-token on a narrow card.

## What to build

The file name reads as one token, `agent-desk/calendar_sync.json`, and wraps onto the next line as a whole when the card is narrow. Other code tokens inside an empty state follow the same rule.

**Blocked by:** None (can start immediately).

**Status:** done

## Scope

- The path text has no padding spaces.
- Empty-state code uses nowrap so a hyphen is not a break.
- The empty row may still wrap the action under the message on a narrow card.

## Acceptance criteria

- [x] The calendar empty state shows the path as a single code token with no surrounding spaces.
- [x] That token does not allow wrapping inside the name.
- [x] The connect action and the overflow item are unchanged.

## Tests

Frontend card suite: the empty calendar card exposes the path token and its nowrap class.

## Out of scope

Rewriting the empty-state sentence. Changing how other cards wrap ordinary words.
