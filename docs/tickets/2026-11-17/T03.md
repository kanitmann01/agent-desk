# T3: The tracker card tells the truth about where its numbers came from

Part of specs/007-real-data-audit-and-settings.md (demo 2026-11-18). Reproduced 2026-11-17:
on the live desk the TRACKER cell reads "Closed Won, this quarter / 412,300 USD /
sample-sales.xlsx" under a SAMPLE DATA stamp, because the desk-level sample switch is on
and the sample instance is the only tracker. A viewer cannot tell a demo fixture from a
real file, and a real tracker's card does not say when it last read its file.

## Context

Brief.tsx decides the sample stamp from data.sample and the SAMPLE_FILE regex; the tracker
figure comes from sampleDesk when the desk is in sample mode, and from the instance card
otherwise. read_tracker already returns file, rowsSeen, labelColumn, valueColumn, value,
delta, direction. The card lacks freshness and provenance language.

## Scope

- The real tracker card shows: the file it reads, the row count it aggregated, and a
  relative "read X ago" line (server adds readAt to the card payload; no schema change to
  the store).
- The SAMPLE DATA stamp stays only where the sample world draws the cell. A real instance
  is never stamped sample, and a sample fixture is never shown without the stamp.
- Settings > Desk explains the sample switch in one line: what it changes, and that real
  trackers still read real files with it on. The demo-day instruction (switch off) lives in
  docs/demo, not only in the settings copy.
- Tests: card payload for a real instance carries file, rowsSeen, readAt; sample payload
  does not claim a real file.

## Acceptance

1. A confirmed instance's dashboard card names its file and row count.
2. Turning the sample switch off leaves the real tracker rendering its own numbers.
3. No cell shows SAMPLE DATA unless the sample world drew it.
