# 04: Working session: fourteen roles, rendered and checked

**What to build:** the Working session template complete: the twelve shared slide roles and its own two (`steps` and `pillars`), in a dark and a light shell. Dense and structured, for taking a team through an analysis: a short kicker line above each title, thin rules instead of boxes, a 2x2 matrix with named axes, pillars, and a chain of steps that reads left to right. Every layout is rendered and looked at.

**Blocked by:** 02: One new slide role end to end.

**Status:** ready-for-agent

- [ ] The shell holds fourteen layouts, one per role, in both variants, and the structural test holds for each: every box inside the half-inch margin, no type below its floor, no gradient, no underlined title, colours only from the palette, and dark and light differing only in colour.
