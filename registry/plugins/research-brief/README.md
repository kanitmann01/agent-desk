# Research Brief

## What it answers

What did the last research question answer, from how many sources, and when?

## What it reads

The latest answer already stored in the local research store: its summary, its source count and its answered time. No workspace file and no endpoint.

## What it never does

It never calls a model or an endpoint, never opens a network connection, never writes to disk, and never shows an answer that was not already stored.

Part of the research and knowledge family. Declarative: the manifest names the
data source and the host supplies every value; the plugin ships no code.
