# Source Ledger

## What it answers

Which sources backed the last answer, and which of them were actually used?

## What it reads

The source list attached to the latest stored research answer, rendered as a table with source, title and used columns. It reads the research-brief data source, so it reads no file of its own.

## What it never does

It never fetches a source, never re-runs the question, never calls a model, and never writes anything.

Part of the research and knowledge family. Declarative: the manifest names the
data source and the host supplies every value; the plugin ships no code.
