# Meeting Prep

Answers: what is the next meeting, and what is on today?

Reads: the calendar bridge's next-event metadata and day view. No other
files and no network.

Shows: upcoming meetings (timeline), next event title, today's events
(list), and attendees of the next event (checklist).

Never invents attendees, agenda items or links, writes to the calendar, or
asks the model. A blank calendar bridge renders blank with the bridge's
cause rather than an empty meeting.
