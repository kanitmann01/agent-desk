# Mail overview

Reads the Outlook Brief's header-only bindings and writes a short
overview.

Use it when the user asks what happened in the mail folder or what to
answer first. Name the active thread count, then the one message that
matters and why, then the suggested first reply. Work from the brief
only: it never carries message bodies, and the overview must not
invent one.
